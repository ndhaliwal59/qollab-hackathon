At the tower

Recover the bits

The decoder uses all eight antenna readings to guess which phone sent each bit. Run it to watch the guesses and quantum-assisted search.

What this models: BPSK signal detection over ray-traced ASU radio paths, with generated bits and noise. Real 5G adds error-correction coding and OFDM; this demo skips those steps. It is not a full 5G modem or live radio.

    How the quantum search helps

    QAOA means Quantum Approximate Optimization Algorithm. It does not decode the whole message: it samples possible changes to the eight least-certain bits. Regular software checks those guesses against the antenna readings. This circuit runs in a simulator, not on quantum hardware.

    H

    Open up the choices

    Hadamard gates put each selected bit into a quantum state that can represent 0 and 1 together.

    RZ · RZZ

    Encode the signal fit

    Single-bit and pair gates represent how each choice affects agreement with the tower’s readings.

    RX

    Shift the chances

    Mixer gates change which bit combinations are more likely to appear.

    M

    Read out guesses

    Measurement gives ordinary 0/1 strings. A classical search checks and refines them.

    About this benchmark

    These are simulated transmissions on held-out, ray-traced Arizona State University channels at 3.5 GHz. Repeated signals share physical channels, so 32,000 transmissions are not 32,000 independent locations.
